# Battle artwork

Original vector artwork for Curious-Y: eight-frame blue/red catapult sheets,
blue/red cavalry mounts, an arrow, and a stone. No third-party assets are
embedded in these files. Edit `scripts/generate-battle-assets.mjs` and run
`node scripts/generate-battle-assets.mjs` to regenerate them.

The catapult winds up during frames 0–3 and releases its stone at frame 4.
Infantry and riders use the existing credited Tiny Swords warrior sheets;
archers use the existing archer sheets. Their source and license are documented
in `../tiny-swords/README.md`.
