# Tiny Swords assets

This folder contains a small curated subset of the **old CC0 edition** of
Tiny Swords by Pixel Frog. The assets are used for the Curious-Y Kingdoms
battlefield preview.

- Original pack: https://pixelfrog-assets.itch.io/tiny-swords
- Author: Pixel Frog
- Edition: `TS_old version_CC0 Licensed` (January 3, 2024 upload)
- License: CC0 1.0 Universal / public domain dedication
- CC0 text: https://creativecommons.org/publicdomain/zero/1.0/

The current expanded Tiny Swords pack has different redistribution terms.
These files were deliberately sourced from the earlier CC0 edition preserved
in the Endless Access Threadbare repository at commit
`d3b9ade9da5cedb7585f60c5da7875cd7b7f8a60`.
